# Spring Boot Learning Repository

This repository follows the **Spring Boot course by Devtiro** and contains my notes, code, exercises, and progress as I work through the course.

The course builds a Spring Boot application from the ground up, covering Spring fundamentals, dependency injection, configuration, databases, JDBC, JPA, JSON, REST APIs, testing, and deployment.

NOTE: At the time I worked on this lesson, I used SpringBoot verision 4.1.0 and 4.1.1 with Java V21 and Maven 3.9.15
---

# 🎯 Goal

The goal of this repository is to build a solid foundation in **Java and Spring Boot backend development** by following a complete application from initial setup through database integration, REST API development, testing, and deployment.

This repository also serves as both a **learning record and a reference** for the concepts and code developed throughout the course.
